# 현재 구현 범위

엔진 `agent-0.3.0` · 추출 계약 기본값 `1.2` · 공개 스키마·체크포인트 `1.0`

## 구현됨

- 디지털 PDF 텍스트 우선 읽기, 품질 부족 페이지의 로컬 OCR 전환, 혼합 PDF와 페이지별 출처 기록.
- 저장 텍스트 기반 AI 분류 A와 선택한 미확인 항목의 PDF 보완 B. B는 명시적으로 실행하며 원본 전체 PDF 전송·추가 비용이 발생함.
- 원시값·AI 제안·검사 통과값 분리, 항목별 오류 격리, 원문 근거와 A/B 후보·사용자 선택 이력 보존.
- 원문 확인 후 후보 선택·직접 수정·보류. 재추출·후보 변경 시 연결 비교 자료의 재확인 요구.
- 독립 비교 묶음, 근로자·사업장·기간·시간 의미 확인, 명세서 상세 항목과 입금 선택·배분.
- 확인한 범위의 R-01~06 자료 대조, 설명 생성, 한글 PDF·선택 원본 ZIP.
- 작업 상태·취소·재개, 누적 호출 예산, 체크포인트, 저장 후 복원과 버전 무효화.

## 남은 범위

- W-01~05 법정 임금 규칙과 R-07 계산 임금 대조. 전체 임금·미지급액·출시 준비 완료를 확정하지 않음.
- 운영 인증·사용자 격리·DB·작업 큐·다중 프로세스 동시성 및 운영 삭제 보장.
- 실제 문서별 AI 정확도·비용 평가와 다양한 실행 환경 검증. 텍스트 일치와 A/B 일치가 원본 확인을 대신하지 않음.

## 검증 범위

저장소 기준 **584개 통과·7개 생략**(원본·선택 PDF 미포함). UI 회귀 5개와 Ruff 검사·106개 Python 파일 포맷 검사를 통과했습니다. 실제 AI 호출은 하지 않았습니다.

자동 회귀는 합성 PDF·저장 응답·가짜 모델 공급자로 그래프, 공개 계약, 로컬 API, 비교·선택·취소 경계를 검사합니다. UI 모의 회귀에는 Node.js가 필요합니다. 비공개 원본과 선택 PDF가 필요한 검사는 자료가 없으면 건너뜁니다.

자동 회귀 결과를 실제 모델 판독 정확도나 실브라우저 검증으로 해석하지 않습니다. 실행 방법은 [저장소 안내](../README.md#범위검사)를 참고하세요.
