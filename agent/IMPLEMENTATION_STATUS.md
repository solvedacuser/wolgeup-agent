```powershell
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe -m ruff check agent

.venv/Scripts/python.exe -m agent.dev.run_fixture demo
.venv/Scripts/python.exe -m agent.dev.run_fixture schemas --output agent/contracts
```

## 백엔드 전달물과 남은 작업

- `agent/contracts/`: 공개 JSON Schema, 4종 작업의 입력·성공 결과, 미지원 버전·취소 예제, 미완료 지원표.
- `agent/ports/runtime.py`: 백엔드가 구현할 비동기 연결 계약.
- `agent/README.md`: 실행·설정·연결 방법과 실패 처리 경계.
- 별도 백엔드 요구사항의 실제 권한·영속성·동시성·다운로드/삭제 검증은 백엔드 담당자와 공동 수행해야 함.
- 법정 임금 규칙의 공식 근거·기간·산식·독립 기대값·프로필 전체 검증은 후속 작업.

`FakePorts`는 개발용이며 운영 결과 확정·프로세스 간 잠금·실제 인증을 제공하지 않는다. 에이전트 자체의 1차 구현 완료와 서비스 출시 준비 완료는 별도로 관리한다.
